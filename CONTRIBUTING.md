# Contributing

The project is currently in its feasibility phase. Discuss scope changes before adding implementation.

- Keep documentation in English by default.
- Use small, coherent commits that describe actual work.
- Add tests alongside executable behavior and record how results were reproduced.
- Preserve train/validation/test boundaries; do not tune against the held-out test set.
- Never commit secrets, private data, or datasets without redistribution permission.
- Attribute reused code and data and comply with their licenses.
- Record known limitations and failed hypotheses.

Original project code is MIT licensed. External datasets retain their own terms; see docs/DATA.md for the BAF license discrepancy and restrictions on redistribution.
